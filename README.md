# Kohinoor Signature Farms

Full-stack web application & admin dashboard for Kohinoor Signature Agro & Livestock Farms.

## 🚀 Deployment to Vercel (via GitHub)

This repository is pre-configured with zero-config Vercel Serverless deployment for both the React frontend and Express REST API backend.

### Quick Steps:
1. Push this repository to your **GitHub** account.
2. Go to **[vercel.com](https://vercel.com)** and click **Add New > Project**.
3. Import your GitHub repository.
4. Leave all default build settings as detected (Vercel uses ercel.json automatically).
5. Click **Deploy**.
